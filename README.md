# FCoV-evolution
### This repository contains data and code to to answer the follwing research question:

1. Identifying key mutations that are responsible for biotype switching between FIPV and FECV
2. Identifying sites that are highly evolvable in intra-host environment, which might be a potential target site for biptype switching
