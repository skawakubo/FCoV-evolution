# FCoV-evolution
## This repository contains data and code to to answer the follwing research question:

1. Charactarize evolutionary relationships between FCoV and other related alphacoronavirus (<em>Tegacovirus</em>)
2. Identify key mutations that are responsible for biotype switching between FIPV and FECV
3. Investigate evolutionary roles of the key mutations (intra-host mutataions or transmissible mutations)
4. [optional] Identify sites that are highly evolvable in intra-host environment, which might be a potential target site for biptype switching
